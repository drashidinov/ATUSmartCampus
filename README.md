# ATU Smart Campus

Адаптивный русскоязычный сайт-каталог студенческих IT-проектов для улучшения университетского кампуса.

## Проекты
1. Smart Campus Vision — обезличенный анализ потоков людей.
2. ATU Smart Access — NFC-доступ в аудитории.
3. ATU Smart Canteen — онлайн-заказ еды.
4. ATU Print Station — станция печати самообслуживания.

## Запуск
Откройте `index.html` в браузере. Сборка и зависимости не требуются.

Для локального сервера: `python3 -m http.server 8000`, затем http://localhost:8000.

## Возможности
- Фильтрация идей по направлению
- Подробности проектов в модальном окне
- Копирование описания идеи
- Этапы работы и структура презентации
- Адаптивный дизайн
